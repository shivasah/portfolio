Additional design reference: Case Study Flip Stack
https://componentry.dev/docs/components/case-study-flip-stack
This release implements the documented interaction with native static-site code;
it does not contain the reference component's implementation or Framer Motion.

Lastoria: the owner supplied the font used to produce the fixed-word vector
lettering. No font file is bundled. The artwork is limited to "shiva".


Character hero (v57):
Runtime and image atlas supplied by the portfolio owner in
luxury-character-hero-q95(1).zip. Original frame bytes are retained, with the
engine adapted for inline portfolio integration and lifecycle suspension. The
source package supplied no separate license text; this integration does not
assert new ownership or licensing terms. No font binaries are distributed.

V110 NOTE LETTERING
The four fixed doctor-note lines are outlined from the handwriting supplied in the owner's report-tools demo. The portfolio preloader supplies only name outlines. No font binaries or embedded font programs are included. A locally installed Lastoria can be used by the browser.
